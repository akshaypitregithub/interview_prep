# Sources and Company Calibration

Checked on 2026-09-05. Official guidance informs the broad preparation areas; the exercise sequence, review cadence, and readiness thresholds are our own curriculum choices. Formats can change by team, role, location, and date.

## Official interview and company references

- [Amazon SDE III / Senior SDE preparation](https://amazon.jobs/content/en/how-we-hire/sde-iii-interview-prep): explicitly discusses coding, system design, behavioral evidence, architectural scope, and leadership. This supports including all three tracks rather than coding alone.
- [Amazon software development interview topics](https://amazon.jobs/content/en-gb/how-we-hire/interview-prep/software-development-topics): includes language, algorithms, data structures, object-oriented design, databases, distributed computing, operating systems, and internet topics; recommends asking the recruiter about relevant subjects. Our foundations track covers these areas.
- [Google hiring process](https://www.google.com/about/careers/applications/how-we-hire): official entry point for hiring guidance. Use role-specific recruiter materials to confirm the actual technical loop; we do not infer round counts from this general page.
- [Apple careers](https://www.apple.com/careers/us/): use specific role/team requirements to choose the specialty branch. This page is not evidence of a universal Apple interview format.
- [Netflix culture memo](https://jobs.netflix.com/culture): describes judgment, candor, responsibility, and collaboration. Use genuine examples to examine fit; this is a culture reference, not a technical interview syllabus.
- Meta: the public preparation pages attempted during setup were not accessible. Obtain the current official preparation guide from your recruiter. No Meta-specific round counts or tool policies are asserted in this course.

## Rust references

- [The Rust Programming Language](https://doc.rust-lang.org/book/): primary learning reference for fundamentals, ownership, enums, collections, errors, and testing. Read relevant sections on demand.
- [Rust standard library](https://doc.rust-lang.org/std/): primary API reference for collection behavior, slices, iterators, and types. Prefer this when an API detail is uncertain.

## Before targeting any company

Create a brief for the specific role with: job link; level and expectations; confirmed round types and lengths; permitted languages including Rust; compiler/editor availability; AI/tool policy; specialty topics; and recruiter-provided preparation links. Mark each item as confirmed or unknown. Calibrate mocks only after this check. Company names do not establish interchangeable levels or identical interview processes.
